# **App Name**: TradeFlow

## Core Features:

- User Registration and Secure Login: Enable users to register with required fields (Full Name, Date of Birth, User ID, Password) and secure login with CAPTCHA, encrypted authentication, and brute-force prevention.
- P2P Ad Creation and Browsing: Allow users to create 'Buy' or 'Sell' crypto ads with various pricing options and payment methods, and browse ads with extensive filtering capabilities.
- Escrow-Based Trade Execution: Facilitate secure P2P trading by locking seller's crypto in escrow upon trade creation, guiding users through trade stages with a visual stepper, and enabling buyer to mark payment.
- Real-Time Trade Chat with Sentiment Analysis: Provide a real-time chat interface between buyer and seller with AI-powered sentiment analysis to detect harmful messages. If the message is flagged as potentially harmful, a red shield icon appears next to the message, with the AI's reasoning shown in a tooltip.
- Dispute Resolution: Implement a dispute system where either party can open a dispute if the trade is stuck, and admins can intervene to resolve disputes.
- Admin Panel for Moderation: Create a comprehensive admin panel for user and trade management, dispute resolution, and configuration of supported coins and chains.
- AI-Powered Ad Copy Generation: Use an AI tool to generate professional terms and conditions for ads, streamlining the ad creation process and improving user experience.

## Style Guidelines:

- Primary color: Light blue (#89bdd3) to establish trust and security.
- Background color: White (#FFFFFF) for a clean, minimal aesthetic.
- Accent color: A slightly darker shade of blue (#72A0C1) for interactive elements and CTAs.
- Font: 'Inter' sans-serif for both body and headlines. This gives a modern, neutral look that provides great readability on a variety of screen sizes.
- Code font: 'Source Code Pro' for displaying code snippets.
- Clean, minimal layout with clear separation of concerns.
- Simple, line-based icons to maintain the clean and minimal design.
